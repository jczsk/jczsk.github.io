## 🎯 解决什么问题？

每天手动翻联盟后台找品、复制文案，太浪费时间了。这个脚本帮你：
- 自动筛选高佣金、高销量商品
- 一键生成带表情符号的朋友圈文案
- 支持导出 Excel 表格

## 🛠️ 怎么用？

1. 安装 Python 3.9+
2. 运行 `pip install -r requirements.txt`
3. 执行 `python main.py`
